

Responsive frontend admin dashboard for Karnel.

Dashboard, Users, Hotels, Restaurants, Resorts, Tourist Spots, Travel Info, Orders, Feedback, Messages, Settings, Login and CRUD-style add forms.

Modern SaaS-inspired sidebar, responsive header, KPI cards, status badges, polished tables, activity feed, dashboard bar visualization, search/filter interactions and mobile navigation.

Open `index.html` in any modern browser.

This package is frontend-only. Connect the forms and tables to your backend/API/database for persistent CRUD and authentication.
